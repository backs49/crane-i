# 그록 빌드 요청 프롬프트

아래 내용을 그대로 복사해서 그록 빌드에 전달하세요.

---

이 저장소는 "몰랑크레인"이라는 바닐라 JS + Canvas 2D 인형뽑기 게임이다 (빌드 도구 없음, `<script>` 태그 전역 공유). 지금부터 `docs/plans/` 디렉터리에 있는 구현 명세서를 실행해 달라.

## 작업 지시

1. 먼저 `docs/plans/README.md`를 읽어라. 프로젝트 아키텍처, 스크립트 로드 순서, 전역 제약이 정리되어 있다.
2. `docs/plans/01-persistence.md`부터 `07-collection-reward.md`까지 **번호 순서대로** 구현하라. 순서를 건너뛰거나 섞지 마라 (2단계는 1단계에, 5단계는 1·2단계에 의존한다).
3. 각 명세서 안의 Task를 위에서부터 순서대로 수행하라. Task의 Step은 "실패하는 테스트 작성 → 실패 확인 → 구현 → 통과 확인 → 커밋" 사이클이다. 이 사이클을 지켜라.
4. 명세서의 코드 블록은 그대로 사용 가능한 완성 코드다. 임의로 개선·리팩터링하지 마라. "이것을 → 이것으로 교체" 형식의 수정 지시는 해당 위치를 정확히 찾아 그대로 적용하라.
5. 한국어 UI 문구(토스트, 버튼, 안내문)는 명세의 카피를 **글자 그대로** 사용하라.
6. Task마다 명세에 적힌 검증 명령을 실제로 실행하고 통과를 확인한 뒤, 명세에 적힌 커밋 메시지로 원자적으로 커밋하라.

## 검증 명령 (명세서에도 있음)

```bash
node tests/fun.test.js
node tests/save.test.js        # 1단계에서 생성됨
node tests/load-scripts.js     # 전체 스크립트 로드 스모크 테스트
python3 -m http.server 8765    # 게임 서빙 (백그라운드)
GAME_URL=http://127.0.0.1:8765/ node tests/chrome-play.mjs   # 브라우저 E2E (playwright 필요)
```

playwright가 설치돼 있지 않으면 `npm i -D playwright-core` 없이 진행하되, chrome-play 검증 단계는 "환경상 생략"으로 기록하고 나머지 node 테스트는 반드시 돌려라.

## 절대 깨면 안 되는 것

- `tests/chrome-play.mjs`의 기존 검증: `#missionBar` 텍스트에 항상 "부탁" 포함, `.dex-dot` 8개 이상.
- `window.__crane.snapshot()`의 기존 필드 (제거·이름 변경 금지, 확장만 허용).
- `index.html`의 스크립트 로드 순서. 새 스크립트는 명세가 지정한 위치에 넣고, `tests/load-scripts.js`의 files 배열에도 반드시 추가.
- 6단계 이후 게임 파일을 수정하는 커밋은 `sw.js`의 `CACHE` 버전 문자열을 올릴 것.
- 외부 라이브러리 추가 금지.

## 명세와 실제 코드가 다를 때

명세의 "교체 대상" 코드가 실제 파일과 미세하게 다르면(줄바꿈, 이전 단계의 변경 반영 등), 명세의 **의도**를 유지하는 최소 수정으로 적용하고, 최종 보고에 어느 파일의 어느 부분을 어떻게 조정했는지 기록하라. 크게 다르면(함수가 없거나 구조가 다름) 그 Task를 중단하고 보고하라.

## 완료 보고 형식

모든 단계가 끝나면 다음을 보고하라:
1. 단계별 완료 여부와 커밋 해시 목록
2. 실행한 테스트와 결과 (실패했다면 원문 출력 포함)
3. 명세에서 벗어나 조정한 부분 목록
4. 생략한 단계/Step과 사유 (예: playwright 미설치)
